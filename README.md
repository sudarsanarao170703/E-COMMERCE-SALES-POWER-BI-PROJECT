# E-Commerce Sales Analysis Dashboard

## Project Overview

This project is an interactive E-Commerce Sales Dashboard developed using Microsoft Power BI. The dashboard provides insights into sales performance, customer behavior, product performance, order status, and regional sales.

## Objectives

* Analyze overall sales and revenue performance.
* Track total orders and customers.
* Identify top-performing products.
* Analyze sales trends over time.
* Understand order status and customer behavior.
* Compare sales performance across different regions.

## Tools and Technologies

* Power BI
* Power Query
* DAX
* Data Cleaning
* Data Modeling
* Data Visualization

## Key KPIs

* Total Revenue
* Total Orders
* Total Customers
* Average Order Value
* Sales Growth
* Top Products

## Dashboard Features

The dashboard includes interactive KPI cards, charts, tables, slicers, and filters. Users can analyze sales based on date, product, category, region, customer, and order status.

## Data Preparation

The raw data was cleaned and transformed using Power Query. Duplicate records, missing values, incorrect data types, and unnecessary columns were handled before creating the data model.

## DAX Analysis

DAX measures were created to calculate important business metrics such as total revenue, total orders, total customers, and average order value.

## Key Insights

The dashboard helps identify sales trends, high-performing products, customer purchasing patterns, regional performance, and order status. These insights can support data-driven business decisions.

## Project Outcome

This project demonstrates practical skills in Power BI, Power Query, DAX, data cleaning, data modeling, KPI development, and interactive data visualization.
